# Documentation Contexte

Mettre ici le contexte projet en format detaille.

## Comment utiliser ce dossier

- Garder chaque fichier focalise sur un seul sujet.
- Preferer des sections courtes et des exemples concrets.
- Mettre a jour ces docs quand les regles metier evoluent.

## Fichiers recommandes

- `domain.md`: regles metier et vocabulaire
- `architecture.md`: frontieres de modules et flux de donnees
- `conventions.md`: conventions de code, tests et revue
- `features/collection.md`: regles specifiques a la feature Collection

## Conseils de redaction

- Utiliser un format type decision record: contexte, decision, consequences.
- Ajouter des dates pour les changements de regles importants.
- Lier les fichiers source pertinents quand une regle fait reference a l'implementation.
